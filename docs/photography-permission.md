# 写真作品・SNS利用の許可

## 現在の簡易ページ（simple-v1）

写真撮影ページは成人本人向けの1ページに簡略化しました。被写体1人・撮影1回の写真一式を対象とし、お名前・掲載範囲（顔出し / 識別できない写真のみ）・年齢を含む同意チェック1つ・サイン1回で「同意して保存」します。署名確定だけの別ボタンや、個々の写真への署名はありません。メールは控え希望者だけ任意入力で、未入力時にはメールサービスを呼びません。インタビューのメール必須・同意フローは変更していません。

用途はSNS・Web/ポートフォリオ・展示・写真集・作品プリント販売をまとめて常時表示します。企業広告、第三者への素材販売、AI学習、顔合成は含みません。利用期間・謝礼も常時表示し、初期値は作品利用「撮影日から1年間」、謝礼「無償」です。今回の撮影条件に合わなければ、運営者が撮影前に変更して説明してください。

撮影場所・日付・作品名・作品利用期間・謝礼・運営者トークンは折り畳みの「運営者設定」に集約。日付と撮影番号は自動セット、場所とトークンの入力は必要です。トークンは画面のメモリ上のみで、リロードすると消えます。「次の方へ」で本人情報・範囲・チェック・署名・撮影番号をリセットし、運営者設定は引き継ぎます。日本語/English切り替えは撮影設定や名前を保持し、未保存の署名・同意チェックをリセットします。保存済み同意書は原文のままです。

短い説明と同意書全文は同じページで確認でき、全文もPDF・サーバー記録に保存します。撤回相談、匿名扱い、個人情報の目的と保存期間、国ごとの法令上の権利を残し、全面的な権利放棄は求めません。18歳未満はこの簡易フォームに署名せず、運営者が別途保護者対応を行ってください。既存の詳細形式・署名済み記録は変更しません。以下の詳細方式の説明は旧形式の資料として残します。

調査日：2026-10-22。日本での人物撮影を想定した運用設計です。すべての街頭撮影で一律の書面同意が法律上必要という断定ではなく、本人を中心に撮影して作品・SNSへ利用する活動で、許可範囲を明確に記録するためのページです。撮影国・利用形態・契約条件に応じて専門家へ確認してください。

## 調査結果

- **撮影と公開を別々に説明・許可取得する。** 撮ってよいことだけで、SNS・作品の公開や販売まで許可されたとは扱いません。JICAのガイドラインも撮影許可と使用・公表の許可を区別し、使用目的・媒体・期間の説明と記録を推奨しています。[JICA 肖像権ガイドライン](https://www.jica.go.jp/about/announce/buppin/detail/__icsFiles/afieldfile/2024/11/01/koji_24a00585_1.pdf)
- **アート作品でも人物の権利を別途考える。** 写真の著作権と被写体の肖像・プライバシーに関する利益は別です。文化庁は写真に写る人物の肖像、他人の著作物の利用への注意を示しています。[文化庁 注意事項](https://www.bunka.go.jp/jiyuriyo/chui3.html)、[文化芸術活動の法的FAQ](https://www.bunka.go.jp/seisaku/bunka_gyosei/kibankyoka/faq/index.html)
- **用途を分ける。** SNS、ポートフォリオ、展示、写真集、作品プリント販売、広告・PRを別選択にします。作品プリント販売の許可で広告モデル利用や第三者への素材販売・再許諾を許可したことにはしません。文化庁の撮影契約書式も第三者の権利処理を別途必要な事項として挙げています。[文化庁 撮影契約の注意事項](https://pf.bunka.go.jp/chosaku/chosakuken/c-template/type06_precution.php)
- **誰が・何を・いつまで・どんな条件で利用するか残す。** 撮影者、案件、撮影日・場所、写真ファイル名または撮影番号、媒体、利用期間、編集範囲、謝礼、匿名・公開名を明示します。SNSのタグ付けは匿名選択では不可とします。原画像はアップロードしません。
- **未成年者・他の権利者への確認。** 本ページの運用では18歳未満は親権者・保護者が説明を受けて署名します。他の人物、背景の著作物、施設の規則や私有地の撮影許可は別確認です。本人の同意書だけで処理できません。海外サービスのリリース要件も参考になりますが、日本法の要件そのものではありません。[500pxのモデル・プロパティリリース要件](https://support.500px.com/hc/en-us/articles/204728157-Release-Forms)
- **撤回・削除相談を設ける。** 公開前は連絡先へ相談できるようにし、公開後も違法・同意範囲外の利用への権利を留保します。売却済みプリントや第三者の転載は回収できない可能性を説明します。全面的な権利放棄や永久の免責を保証しません。
- **個人情報の目的と保存方針。** 氏名・メール・署名は控えと同意証拠に用い、公開素材と分離します。利用目的の明示が必要となる点は個人情報保護委員会のFAQも参照してください。[入力フォームでの利用目的明示](https://www.ppc.go.jp/all_faq_index/faq1-q4-17/)

## 実装

- ヘッダー「写真撮影許可」→ `/photo-consent`。インタビューのZustand状態、撮影ID、履歴とは独立したフォームです。言語設定のみ共通です。
- 用途・撮影許可のチェックは初期値OFF。必須情報を確認後、顔・全身OK / 後ろ姿・手元のみを選びます。写真には声のみ選択やインタビュー音声利用はありません。
- 氏名・メール・年齢・必要なら保護者氏名、約款、個別確認、手書き署名を保存。既存の認証された同意保存APIを使い、`purpose: photography` と写真専用の条件をサーバーでも検証します。
- 保存・メール送信には既存 `CONSENT_*` / Resend設定を使います。メール未設定時は未送信と明示。写真専用の同意書タイトル・メール件名で控えPDFを生成します。長文は複数ページになります。認証付き電子署名や本人確認ではありません。
- 同意JSON/PDFは専用サーバー領域に保存し、ブラウザ履歴は `masking-human-photo-permissions` のIndexedDBへ別保存。インタビュー履歴には混ぜません。署名なしでは写真公開の許可を得たことになりません。
- 記録保存は既存設定の「撮影日から1年間」。写真の利用許諾期間は案件ごとに別途必須入力です。長期展示・販売で1年後も同意証拠が必要なら、実態に即した記録保存方針へ変更して説明してください。自動削除は未実装で、運営者の管理が必要です。

## インタビューとの違い

インタビューは冒頭のチェック（会話・記録への同意、掲載予定と終盤署名の確認）→ 会話 → ログ除外 → 分析候補確認 → 最終分析 → 最後に掲載範囲選択・署名という順序です。冒頭のチェックだけを公開許可と扱いません。最終署名のない履歴は素材保管にとどめ、公開不可です。写真ページは撮影前の許可取得を案内します。

実メール・実署名・実撮影での法律上の有効性は本開発では検証していません。本番運用前に撮影地・用途に合わせて専門家へ確認してください。
