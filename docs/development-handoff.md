## 現在の体験

- `/` と `/voice` は `/live` に統一。準備 → 同期合図 → 会話 → 除外する発言の確認 → 分析候補の確認 → 最終分析・掲載署名。
- コスメは会話の入口のみ。短い共感と一度に一つの質問で、その人の記憶・選択・人生へ自然に展開します。
- 日本語・英語UI。英語モードでは最初の実質的な発言に応じて他言語のインタビューへ適応します（UI言語とは別）。
- スマホはチャット／マインドマップを切り替える単一表示。図の新規ノードは大きなポップ演出、待機状態は実際の処理段階を表示。
- 分析は原文・非除外発言に基づく5分類。語句の重複・根拠のない因果を避け、統計は会話に基づく参考情報で心理診断ではありません。
- 最終画面に動画編集やSNS保存を挟まない。これらの操作は履歴詳細の「素材保存・SNS書き出し」に集約。
- `/photo-consent` は日本語・英語の簡易撮影許可ページ。撮影セッション単位、成人向け、一つの署名。広告・ストック再許諾・AI学習等は別許可。世界共通で法律問題を完全に防ぐ保証はありません。

## 最新の編集素材出力

本人映像は別のカメラで撮影。iPad側は外付けマイクの本人音声と、AIの直接音声を収録し、編集に使う方針です。参加者向け画面には編集用UIを追加しません。

- 新しい収録から混合音声、本人／AI別音声、チャット・マップ更新・表示切替・音声状態イベントを保存。
- 会話終了時に履歴へ保存し、最終結果で分析・除外・同意情報を更新。
- 履歴から元音声、WAV変換、ZIP、SRT・CSV、最終図JSON/TXT/SVG、イベント列、オフライン再生HTMLを取得。
- 時刻は観測値であり、文字起こし遅延や録音開始誤差があります。HTMLは近似的な再現で、実画面動画ではありません。
- 古い履歴に存在しない別音声・イベントは復元できません。除外発言も生素材には含まれるため公開前に確認が必要です。
- 未実装：チャット／マップのアニメーションMP4出力、外部カメラ素材の自動同期、途中クラッシュの耐久保存、クラウドへの履歴同期。
- iPad実機・外付けマイク・本番API音声・実メール送信は未検証です。

主な実装は `src/hooks/use-session-recorder.ts`、`src/lib/recording/editing-*.ts`、`src/components/live/history-editing-downloads.tsx`。詳細は [動画制作](video-production-template.md)。

## 設定と移行しないデータ

- `.env.local`、`private-consents/`、ブラウザIndexedDBはGitHubに含まれません。履歴・録音・署名は同じアカウントでも自動移行しません。元端末を残し、必要な素材を履歴から別途バックアップしてください。
- 本番会話にはサーバー側 `OPENAI_API_KEY` が必要。UI開発はデモで進め、課金を避けてください。
- 掲載同意保存は `CONSENT_ORGANIZER`、`CONSENT_CONTACT`、`CONSENT_RETENTION`、絶対パスの `CONSENT_STORAGE_DIR`、32文字以上の `CONSENT_OPERATOR_TOKEN` を運用先で設定。トークンを公開変数・チャット・Gitに貼らないでください。
- 運用者の氏名・連絡先は元端末の設定を安全に移行してください。保存期間は撮影日から1年間という方針です。期限到来時の自動削除は未実装。
- 保存先は端末固有パスをコピーせず、移行先で安全な永続ストレージを指定。クラウド開発環境の一時ディスクを実際の署名の保管場所にしないでください。
- メールサービスは未設定。保存できたこととメール送信・配送完了は別です。
- 履歴に操作を置いているだけで、運用者ログインによるアクセス制御を実装したわけではありません。

詳細：[掲載同意](publication-consent.md)、[写真許可](photography-permission.md)、[収録](interview-production.md)。
