# 低コスト音声方式と常時料金表示（D26）

[English](en/low-cost-voice.md)

更新日：2026-10-30。実装と設定手順。実音声の品質・月額の実測は未確認。

## レビュー後の補強（D31・従来記述より優先）

- パスワードは8文字以上を維持しscrypt比較。Cookie署名は別の秘密鍵へ分離。開発時はGit管理外の `private-usage/session-secret` を権限600で自動作成。本番は `INTERVIEW_SESSION_SECRET` に暗号学的乱数32文字以上を設定必須（例：`openssl rand -hex 32`）。パスワード・秘密鍵の変更で旧Cookieは無効。端末ログアウトはCookie削除であり、流出済みCookieの全失効には秘密鍵変更が必要です。
- 成功・失敗とも15分につきローカル全体5回、Supabaseは送信元5回・全体30回に原子的制限。公開前に `007_operator_attempts.sql` も適用。保存障害はログイン拒否、制限時は429・15分後の再試行を案内。任意IPヘッダーを信用しません。DoSを完全に防ぐ保証ではありません。
- HTTPS終端が別ホストなら `INTERVIEW_APP_ORIGIN=https://your-host.example` を設定しOrigin照合・Secure Cookieへ使用。既存管理POST2経路のみCookieを免除し、各 `X-Admin-Key` 認証は維持。Vercel標準CronのGETに対応したわけではありません。
- 既定予算$5（明示設定優先）。VercelはSupabase必須。他の本番ファイル保存は永続ディスク単一ホストで `INTERVIEW_USAGE_STORE=file` を明示した場合のみ。ロック障害は安全側で停止し、古さだけで生存中ロックを奪いません。残存ロックは全書込み停止を確認して運営者が除去します。
- VADは約1秒の先行音声を保持し、通常400ms・AI読み上げ中600msの連続発声を要求。文間も同じAI発話として中断を記録。空の文字起こしでは中断した音声／返答を一度だけ再開し、連続雑音は停止・手動再開を案内。新規の復帰リクエストは料金対象です。雑音の誤文字起こし・回り込みを完全除去する保証ではありません。
- 終了時の失敗・保留音声区間を利用量履歴へ保存し、確認画面・履歴で録音確認を案内。会話文の捏造や終了後の有料自動再送はしません。STTタイムアウト55秒、返答404は同じプライバシー・単価条件で予備へ一回切替。
- 未確定料金の上流照会による自動精算、PCM実サンプルレート、iPad/外付けマイクの雑音・同期は未実装／未検証。予約を$0として解除しません。公開前の実機・実DB確認は必要です。会話・同意・署名条件は不変です。

## 方式と維持する体験

準備画面の「会話方式・運営者ログイン」から低コスト方式を選択します。従来のRealtimeが初期値で、実機比較後に標準変更を判断します。デモは有料AI APIを呼びません。企画説明、一問ずつ、非誘導、拒否・訂正、日英UI、英語モードの多言語指示、10分制限、発言の修正・除外、本人確認、掲載署名・PDF・履歴は継続します。

OpenRouterの同じサーバーキーで以下を使用します。

| 処理 | 初期モデル | 単価の扱い |
| --- | --- | --- |
| 文字起こし | `openai/whisper-large-v3-turbo` | 秒数。利用報告額を優先、不明なら秒数から推定 |
| 返答 | `google/gemini-3.1-flash-lite` | 入出力トークン。実行時の上限単価を指定 |
| 返答の予備 | `openai/gpt-oss-120b` | 429・一部タイムアウトHTTP応答・5xx時に一度だけ。ネットワークの成否不明では自動再送しない |
| 読み上げ | `heygen/heygen-voice-1-turbo` | 文字数から推定。初期声 `nadine`、PCM16LE・44.1kHz・モノラルとして再生 |

新規接続時に公開カタログで料金・声・モデルを検証します。入力単価上限は文字モデル$4/100万トークン、STT $0.00001/秒、TTS $8/100万文字。出力もモデル別の同じ数値上限を適用。取得できない・上限を超える場合は開始しません。カタログの単価は会話単位で保存し、声はサーバー設定で固定します。品質や提供継続を保証する許可リストではありません。

声の環境設定がない場合、聞き手のman演出は `bram`、それ以外は `nadine`。選んだ声と開始時の指示を会話に固定し、途中の環境設定変更を混在させません。

録音に使うマイク・AudioContextを共有し、AudioWorkletで16kHzへ変換。開始前の音を最大約0.5秒保持し、約1.1秒の無音で発話終了を検出。35秒を超える回答は文字起こしだけ分割し、話し終わるまで返答を作りません。VADは音量に基づく簡易方式で、現場雑音・相づち・音声の回り込みは実機調整が必要です。

返答テキストの完成後、文ごとに読み上げを依頼し、次の文を先読みします。PCMは受信中から再生します。LLMの文が生成された瞬間から読み上げる方式ではありません。割り込み時は再生・返答待ちを停止し、再生済みの文と中断マークを履歴へ残します。中断した文の全文が画面にある場合もあるため、正確な単語単位の再生範囲ではありません。共通時計とAI音声出力を既存の録音・分離トラックへ接続します。

会話履歴は削らず、最大100発言・合計50,000文字まで送信。超過時はエラーとし、拒否・訂正を黙って消しません。自動要約による履歴圧縮は未実装。反復検知の短い注意は最大2回で、新たな判定AIを呼びません。マップ・統計・既存レポートの解析をローカル処理のまま保ち、終了時の追加LLM呼出しはしません。

## 設定

Git管理外の `.env.local` に設定します。キーやパスワードはチャットや `NEXT_PUBLIC_` 変数に入れません。

```dotenv
OPENROUTER_API_KEY=your-server-side-key
INTERVIEW_OPERATOR_PASSWORD=your-random-password-at-least-8-characters
INTERVIEW_MONTHLY_BUDGET_USD=10
OPENROUTER_TTS_VOICE=nadine
```

ローカルの料金保存先はGit除外の `private-usage/`。開発・テスト時は `INTERVIEW_USAGE_DIR` に絶対パスを指定して変更できます。本番ローカル実行ではプロジェクト内の固定ディレクトリを使用し、デプロイ成果物には台帳を同梱しません。ファイルをロックし、同時更新を直列化します。破損時に空の台帳へ戻しません。異常終了で `.lock` ディレクトリが残った場合は、書込みプロセスがないことを確認してから運営者が削除します。料金台帳・予約はバックアップ対象です。

複数Vercelインスタンスで使う場合は、既存Supabaseに `supabase/migrations/006_interview_costs.sql` を適用し、サーバーに `SUPABASE_URL` または `NEXT_PUBLIC_SUPABASE_URL` と `SUPABASE_SERVICE_ROLE_KEY` を設定します。テーブルはservice roleだけに許可し、revision比較で競合更新を再実行します。SQLファイルを追加しただけでは既存DBには反映されません。Vercelで共有保存先がない場合は課金処理を開始しません。ローカルでもSupabase設定があるとDBを使用し、接続失敗時に別の空台帳へ切り替えません。

共有DBでは月間の合計カウンターと会話ごとの明細を別保存し、RPCは対象会話と月間合計だけを返します。月内すべての明細を3秒ごとに転送しません。読み取りだけの照会はrevisionを書き換えず、明細変更と月間合計更新はDBトランザクションで同時に確定します。

準備画面から運営者パスワードでログインします。8時間の署名付きHttpOnly/SameSite cookieを使用し、HTTPSではSecureを付けます。パスワードをlocalStorage・会話JSONに保存しません。パスワード設定時はデモを除く全APIに運営者認証を適用します（ログイン・ヘルスは例外）。Vercelではパスワード未設定のAPIも停止します。参加者用の公開ログインや外部へのレポート配信機能ではありません。

OpenRouterと各接続先による処理を準備画面で説明し、リクエストには `data_collection: deny` を付けます。これだけで全事業者の保持条件が同一になるとは扱いません。運営開始前にOpenRouterの入力出力ログ設定・採用先のデータ取扱いを確認します。

## 料金・予算

D30：APIキーの月間上限と、購入済みクレジットは別です。開始ボタンと新規接続時に読み取り専用APIで残高を確認し、$0なら録音開始前にクレジット追加を案内。確認APIの失敗を$0と決めつけず、上流の402は残高・キー上限の確認を案内します。確認だけでは有料音声を生成しません。

会話中のヘッダーはスクロール時も残り、今回・今月の金額を4桁で表示。内訳にはモデル・文字起こし・返答・音声・予備モデルへの切替を表示します。3秒ごとと処理完了時に更新し、更新遅延・集計中・不明を表示。$1、80%、100%の到達状態を常時見える場所へ表示します。アプリ内通知であり、メール・OS通知は送りません。履歴にはスナップショットを保存し、「最新の料金を確認」で再取得・再保存できます。利用量JSONへも含め、本人向けPDFや編集用素材の画面へ料金を焼き込みません。

OpenRouterの `usage.cost` があれば「報告額」、トークン・秒数・文字数による計算は「推定」、成否不明は「確認待ち」です。事業者の報告額も請求書の確定額ではありません。TTSはストリーム完了時に文字数から推定し、中断・不明な処理には金額を捏造しません。2分以上残る処理中の記録も確認待ちへ移し、仮確保は維持します。

月間予算はこのアプリのOpenRouter処理のみです。OpenAI Realtime、他のアプリ、購入手数料・税・ホスティングは含みません。UTCの会話開始月に計上し、月をまたぐ10分の会話も開始月へ記録します。異なる月の利用額や旧Realtime履歴を新方式の$0として補完しません。

実行前に最大トークン数・UTF-8バイト数等から保守的に仮確保し、同じリクエストIDの再実行は拒否します。完了時に差額を解放し、成否不明では仮確保を維持します。予算不足なら新規AI処理だけを拒否し、録音・終了・履歴保存は可能です。再開ボタンは新しい有料リクエストになることを明記します。事業者側の単価変更・請求遅延があるため、厳密な請求上限の保証とはしません。OpenRouter側のキー上限も併用してください。

## 検証と切り替え条件

単体テストは認証、同時予約、永続保存、予備モデル、成否不明、音声契約、終了中の最終文字起こし、初期化中の終了、日英表示をスタブで確認します。実際の課金を発生させるテストではありません。

2026-10-30：隔離したPGliteのメモリDBでも006のSQLを実行し、予約→精算の合計、古いrevisionの拒否、anonからのRPC実行拒否を確認。実際のSupabase接続やデプロイへの反映を意味しません。

新方式の標準化前に、日本語・英語それぞれの10分会話で、語りやすさ、非誘導・反復、話し終わりから最初の音声までの時間、割り込み、iPad・外付けマイク、外部映像との同期、実際の課金を確認します。ここで得られる結果とモック成功を区別します。
