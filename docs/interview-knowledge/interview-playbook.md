# 聞き方の実践集

[English](en/interview-playbook.md)

更新日：2026-10-23。現行指示 [R1] と提出資料 [S1] を照合した開発・レビュー用ノウハウです。応答例はすべて編集した創作例で、実際の参加者の発言ではありません。

## 次の質問を選ぶ

1. 本人が実際に語ったキーワード、出来事、感情を拾う。声の硬さだけで心理状態を断定しない。
2. 既に答えたこと、話したくないこと、未確認のことを区別する。この整理はモデルへの指示で、永続的な構造化データとしての実装保証ではない。
3. 本人が続けたい話に自然につながる未確認の焦点を1つ選ぶ。
4. 語られた範囲を短く受け止め、1つだけ聞いて待つ。通常2文・15秒以内を目安とする。
5. 終了・拒否・安全上の停止では質問を足さない。同意や安全確認にはYES/NOを許容する。

コスメは入口の1〜2問を目安にするが、本人が続けたいなら尊重する。暮らし・仕事・趣味などへ広がったら、その話を主題にする。商品や家族の話へ戻すことを目的にしない。[R1]

## 状況別の判断

| 状況・手がかり | 推奨する対応・創作応答 | 避ける対応 | 根拠・区分 |
| --- | --- | --- | --- |
| 会話の開始 | 温かい挨拶と「最近よく使っているコスメを、ひとつ教えてください」 | 自己紹介の強制、唐突な人生観の質問 | R1・現行指示 |
| コスメを使わない | 本人の日常の習慣へ。「普段、気分を切り替えるためにしていることは何ですか？」 | 美容習慣があることを前提にする | R1・対応方針あり。例は創作 |
| 事実だけの短い回答 | 答えやすい最近の場面を一つ聞く | 同じ質問の反復、短答を拒否と断定 | R1・S1 |
| 「特に感じない」 | 変化がないことを受け止め、別の日常へ | 「本当は安心するのでは」と感情を追加 | R1 |
| 沈黙 | 考える間を尊重する | 質問を重ねる、無言から感情を推定 | R1・S1。待機秒数は未決 |
| 感情や理由が出た | 場面→行動→本人の感情→理由や変化を一焦点ずつ聞く | なぜの連発、最低3回の義務化 | R1・S1の回数規則を限定 |
| 話が別の経験へ広がる | 本人の関心を追い、時間が迫れば短く要約して締めへ | コスメへ強制的に戻す | R1を採用。S1の「本題へ戻す」を限定 |
| 矛盾する発言 | 時点や場面の違いを一問で確認する | 嘘と決める、黙って新しい発言で上書き | 確認の具体的手順は提案。解析上の優先規則は未決 |
| 話題を拒否 | 深掘りを止める。別の話題へ進むか本人の意向を確認 | 拒否した項目を言い換えて再追及 | R1 |
| 会話の終了を希望 | 感謝して終了を尊重。運営者は終了操作で確認画面へ | 継続を説得、最後に追加質問 | R1・R5。発話による自動停止保証は未確認 |
| 悲しみ・不安 | 本人が述べた気持ちだけを短く受け止める | 解決策、称賛、トラウマの追及 | R1・S1 |
| 解釈への否定 | 訂正を受け入れ、本人の言葉に沿って修正する | AIの解釈を正当化 | S1・R4・R5 |
| 締め | 「ひとことで言うと、今のあなたが大切にしたいことは何でしょうか？」。回答を尊重して感謝 | 最重要を強制、コスメの意味へ回収 | R1 |

## 質問の選択肢

場面再現、比較、五感、原体験、仮定、第三者視点、要約の7アプローチから、直前の話に合うものを選びます。すべてを順番に実行しません。第三者視点は本人が挙げた人についての想像であり、その人の本音や客観的事実として記録しません。[R1]

## 提出資料の例を使うときの修正

- 「乳液を使う」から「潤ってホッとしますよね」を足さない。本人が気分を語るまで未確認。
- 「誰から教わった」は教えた人の存在を前提にする。背景が不明なら「使い始めたきっかけは何でしたか？」と聞く。
- 本人が娘に触れる前の「今は娘さんと」は使わない。提出資料の該当会話には発言順序の不整合があり、原画像未確認。
- 「どんな場面や気分」は二焦点。「どんな場面で使いますか？」に絞る。
- 「それは素敵ですね」は固定句にしない。苦痛を称賛せず、語られた内容に合う受け止めにする。

## 入口から締めへの創作例

これは遷移を示す短縮例です。実際の10分の台本や、必ずこの結論へ導く模範解答ではありません。

> AI：こんにちは。最近よく使っているコスメを、ひとつ教えてください。
>
> 本人：赤いリップです。仕事の前につけると切り替わります。
>
> AI：仕事の前に気持ちを切り替えるんですね。最近、その切り替えを感じたのはどんな場面でしたか？
>
> 本人：新しい企画を発表した朝です。自分で考えた案を初めて出しました。
>
> AI：自分で考えた案を初めて発表した朝だったんですね。そのとき、どんな気持ちでしたか？
>
> 本人：怖かったけれど、自分で決めて動けたことがうれしかったです。
>
> AI：自分で決めて動けたことがうれしかったんですね。そうした選び方は、以前と比べてどう変わりましたか？
>
> 本人：以前は人に合わせていました。今は小さくても自分の考えを伝えたいです。
>
> AI：今は自分の考えを伝えたいんですね。ひとことで言うと、今のあなたが大切にしたいことは何でしょうか？
>
> 本人：自分で選ぶことです。
>
> AI：自分で選ぶことを大切にしたい、と話してくれましたね。今日はありがとうございました。

この例の最終回答だけから「最も重要な軸」や客観的な因果を認定しません。実際の指示の変更は [共通プロンプト](../../prompts/interviewer.md) とスタイルに反映します。
