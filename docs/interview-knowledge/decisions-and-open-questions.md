## 未決・要検証の事項

| 優先度 | 項目 | 今わかること／確認すること |
| --- | --- | --- |
| 高 | 原出典の追跡 | NotebookLMの元資料タイトル・URLまたは資料ID・ページ・引用対応表が未受領。特に「10%」「3〜6回」と実例の原画像を確認する |
| 高 | 終了発話の扱い | ボタンと時間制限の終了処理はある。発話だけで確実に止める要件・検出・例外処理は未確定。話題拒否と全体終了は分ける |
| 高 | 途中終了・削除希望 | 終了操作は既存ログを確認へ渡し、可能なら履歴保存。「やめたい」を全データ削除同意とみなさず、破棄・保管の運用と専用操作を決める |
| 高 | 矛盾・訂正の分析 | 単純な新旧優先を採用せず、両発言の文脈・訂正意図・除外をどう保持するかを決める |
| 高 | 実音声の品質基準 | 評価案は作成。対象ケース数、採点者、閾値、再試行条件と実音声評価は未完了 |
| 中 | 沈黙・短答への対応 | 待つ方針はあるが、秒数、再質問回数、終了案内の閾値は未設定 |
| 中 | 原文抽出の精度 | 固定辞書・正規表現のため言語・否定・皮肉・文法の限界がある。改善範囲と評価用データを決める |
| 中 | 公開・保存・同意の運用 | 現行約款を参照。新たな全面免責を追加せず、専門確認・本人確認・期限管理等を運用で詰める |
| 中 | 実機・同期・配送 | iPad、外付けマイク、外部カメラ、実メール配送を確認する |

## 今回の範囲

原資料の保存、現行仕様との照合、実践集・評価案・未決事項・出典台帳の作成、旧資料からの導線整備まで。プロンプト、解析ロジック、同意文言、画面の変更は含めません。原資料の不足を推測で埋めず、将来の機能を実装済みと記載しません。
