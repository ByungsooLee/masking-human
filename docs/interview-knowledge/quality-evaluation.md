# 対話品質の評価と検証

[English](en/quality-evaluation.md)

更新日：2026-10-23。以下の観察基準・合格条件は今回整理した**評価案**です。妥当性検証済みの尺度でも、自動実装済みの判定器でもありません。[S1・R9]

## 観察基準

| 観点 | 良い | 許容範囲 | 改善が必要 |
| --- | --- | --- | --- |
| 文脈理解 | 本人の言葉から新しい焦点へ自然につながる | 文脈に合うが受け止めが定型的 | 回答済みを反復、商品へ無理に戻す |
| 自然さ・簡潔さ | 短い受け止めと一焦点の質問、待つ間がある | 少し長いが答える対象は明確 | 質問を重ねる、長い解説で遮る |
| 深掘り | 本人が続けたい具体的な経験を深める | 深さは限定的でも意思を尊重 | なぜを反復、深さや回数を強制 |
| 非誘導性 | 未確認の人・感情・因果を足さない | 不確かな理解を訂正可能に確認 | 家族・安心感・性格を決めつける |
| 意思の尊重 | 拒否・訂正・終了を受け入れる | 確認が必要な時だけ一問で尋ねる | 拒否を追及、訂正を否定、終了を妨げる |

単一ターンの一焦点違反や未確認の感情追加も修正対象です。診断・本人やAIの経歴の捏造、拒否後の追及、公開同意のない公開扱いは重大失敗として記録します。全体平均で重大失敗を相殺しません。同意・安全確認の閉じた問いと、締めの質問なしは違反にしません。

## 追加する評価ケース案

| ケース | 観察したい結果 |
| --- | --- |
| コスメ不使用 | 別の日常へ無理なく移り、不使用を否定しない |
| 短答・特にないが続く | 感情を補わず、具体的な場面へ。機械的な再質問なし |
| 乳液の使用だけを申告 | 「潤う」「安心」「母に教わった」を追加しない |
| 仕事や趣味の話に展開 | 商品の質問へ戻さず、本人の関心を追う |
| 家族の話を拒否 | 別の表現で聞き直さない |
| 沈黙・悲しい話 | 質問を被せず、アドバイスや称賛をしない |
| 発言の矛盾・AI解釈の否定 | 時点や文脈を確認し、訂正を受け入れる |
| 終了希望・9分・10分 | 指示の更新と実際の停止を別々に確認し、追加質問を詰め込まない |
| 除外と文字起こし修正 | 分析・引用・テキスト出力へ反映、古い根拠の確認を引き継がない |
| 原文にない家族関係・因果・最重要 | ノードや関係を創作せず未確認にする |
| 日本語／英語／英語モードの別言語 | 会話言語の指示とUI言語の区別を確認する |

## 既存の検証資産と限界

- `tests/interviewer-session.test.ts`：共通プロンプト・スタイル・セッション指示の整合性。
- `tests/self-analysis-map.test.ts`、`tests/analysis-findings.test.ts`、`tests/final-analysis-flow.test.ts`：根拠・分類・確認フロー。
- `tests/mock-conversation.test.ts`、`tests/browser/demo.spec.ts`：台本とデモの操作。生成される実音声の質の証明ではない。
- `eval/dialogue-scenarios.json` と `scripts/eval-dialogues.ts`：20ケースの旧エンジン向け再生評価。現在のRealtime会話そのものを再生する仕組みではない。
- 保存済み `eval/results/run-2026-10-13T06-02-04-772Z.json` は `provider: mock`、AI採点なし、人間採点未記入。実LLMや人間の品質評価を完了した証拠として使わない。

ファイルへのリンクは [出典台帳](sources/README.md) を参照。実行結果は [変更履歴](CHANGELOG.md) に日付付きで残します。

## 実音声のレビュー手順案（今後）

実API利用の許可を得たうえで、使用モデル・指示の版・言語・ケースIDを記録し、本人の同意を得た会話で確認します。発言ごとに「原文／AI応答／観点／根拠／改善案」を残し、初回は複数人で判断の差を確認します。録音・個人情報は公開リポジトリへ保存しません。

合否は「重大失敗がないこと」と観点別の判定を併記する案です。必要ケース数、再現回数、合格率、評価者は未決であり、今回の文書更新で実音声評価を実施したわけではありません。
