# 現行仕様と実装の所在

[English](en/current-spec.md)

更新日：2026-10-23。区分は [索引](README.md)、出典記号は [台帳](sources/README.md) を参照。

## 目的と成功条件

本人が話したい範囲で、日常の習慣から具体的な経験と大切なことを言葉にできる体験を目指します。語る内容の深さ、家族の登場、涙、価値観の発見を達成条件にしません。「特にない」「まだわからない」も有効な結果です。[S1・R1]

## 参加者の体験（現行実装）

準備 → 同期合図 → 会話・収録 → 発言の修正・除外 → 分析候補への本人確認 → 最終分析・掲載署名。動画編集やSNS素材保存は履歴詳細に集約されています。`/` と `/voice` は `/live` への入口です。[R2・R5]

| 項目 | 現在の扱い | 根拠 |
| --- | --- | --- |
| 本番音声 | 約10分。接続後にAIから開始し、9分で締めの指示、10分の制限で終了処理へ | R1・R3 |
| 会話段階 | 0〜1分：入口、1〜3分：日常への橋渡し、3〜8分：経験の展開、8〜10分：言葉化・まとめ。時刻は会話設計の目安 | R1 |
| 質問数 | 現在の音声会話に旧エンジンの最大8問は適用しない。通常は短い受け止め＋1つの焦点・1問 | R1・R3 |
| 深掘り | 印象的な経験1〜2個を軸に3〜6段階を目安。回数達成や「なぜ」の連発を優先しない | R1 |
| 聞き方 | default / reflective、聞き手の年代・ジェンダー表現を準備で選択 | R1・R3 |
| 言語 | 日本語・英語UI。英語モードは最初の実質的な回答から会話言語を適応する指示。日本語モードでは冒頭による自動切替なし | R3 |

## 分析・本人確認（現行実装）

対象は空でない、除外されていないゲスト発言。AIやホストの語を本人の事実として使いません。追加のAI呼び出しを行わないローカル解析です。[R4]

- 中心は「コスメから紐解く自分の軸」。主枝は「きっかけ・悩み」「原体験・記憶」「現在の習慣・感情」「未来・継承」「コアな価値観」の固定5分類。
- 各分類の表示は最大4語、計最大20ノード。同じ表記は1ノードに統合。異なる表記の同義語統合はしません。
- ノードは原文に存在する語句。辞書と簡易ルールによる候補であり、意味理解の完全性はありません。抽出率10%や可変5〜6分類は未採用です。
- 理由の矢印は、本人が理由を明示した文で両端が一意に決まる場合のみ。否定や曖昧な候補は接続せず、表示関係は最大8本。複数回の深掘りや物語のつながりだけで因果を認定しません。
- 雲形のコア軸は「一番・最も・最重要」等の明示と一意な候補が条件。「ひとことで」の回答や確認画面の承認だけでは最重要に昇格しません。
- 本人は根拠とともに「合っている／少し違う／まだ分からない」を確認。未回答・否定・不明を合意済みとせず、根拠本文が変われば確認を引き継ぎません。
- 数値は発言・辞書・表示ノードの集計であり、心理状態、能力、強み、アイデンティティの測定値ではありません。

事実／本人の解釈／本人の感情／AIの仮説を区別するのは記述上の原則です。提出資料にある3要素分類エンジンが現在の音声フローに一律実装済みという意味ではありません。[S1・R4]

## 成果物・記録・同意

本人の引用を用いる誌面は3構成×3配色。履歴から録音、本人／AI別音声、SRT・CSV・ZIP、マップSVG/TXT/JSON、イベント、近似再生HTML等を取得します。旧履歴にない素材は復元できません。[R2・R7]

発言は行単位で除外でき、ゲストの文字起こしと時刻を修正できます。除外は分析・公開用テキストへ反映しますが、原録音・映像自体は自動で切除しません。[R5・R7]

掲載同意は現在のコードと [同意文書](../publication-consent.md) を参照します。Aは顔・声・全身、Bは声のみ、Cは後ろ姿・手元のみ／顔カット・音声使用可（必要に応じ加工）です。顔や声の加工は自動実装されていません。冒頭チェックは公開許可ではなく、最終署名が必要です。18歳未満は保護者氏名と保護者の署名を扱いますが、自動本人確認はありません。既存署名の利用範囲を新条件で拡張しません。[R6]

これは同意機能の実装記録です。法的有効性を今回確認したものではなく、提出資料から新しい撤回不可・免責条件を追加していません。

## 環境と残る限界

デモ以外の音声にはAPIキー、同意保存には運用先の専用設定が必要。秘密値はGitに含めません。履歴は端末・ブラウザのIndexedDBに依存し、クラウド共有、途中クラッシュの耐久保存、外部動画の自動同期、アニメーションMP4は未対応です。[R2・R7・R8]

実API音声の会話品質、iPad・外付けマイク・外部映像の同期、実メール配送は未検証として引き継ぎます。モックや単体テスト成功でこれらを完了扱いしません。
