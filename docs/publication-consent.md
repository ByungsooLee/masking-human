# 撮影・掲載同意と控え

## 2026-10-22.2 の更新

年齢、収益化・PR・商業利用、公開後の撤回・権利主張に関する確認を個別の必須チェックとして保存します。チェックは初期状態で未選択です。権利主張の制限は同意範囲内かつ法令上認められる範囲に限定し、法令上の権利・違法または範囲外利用への請求・免除できない責任を除外します。一律の全面免責を保証するものではありません。参考：[消費者庁の免責条項に関する解説](https://www.caa.go.jp/policies/policy/consumer_system/consumer_contract_act/annotations/assets/consumer_system_cms203_230915_12.pdf)。本件への適用や約款の有効性は専門家に確認してください。

Option Cは顔カット・音声使用OK（必要に応じ加工）に変更しました。既存の署名済みPDF・記録は変更しません。旧同意で禁止されていた声の使用を新ルールで許可したことにはならず、新しいインタビューには最新版での署名が必要です。氏名・メール・署名キャンバスは既存の入力欄を継続利用します。

## 運用前の必須設定

本番の約款は法律専門家の確認を受けてください。手書きキャンバスは本人確認・認証付き電子署名・法的紛争の完全防止を提供しません。公開後の撤回条項も法令上の権利を排除しません。

既存の `.env.local` に下記の専用設定を追加します。OpenAI APIキーは使いません。

```
CONSENT_ORGANIZER=実際の主催者名
CONSENT_CONTACT=contact@example.com
CONSENT_RETENTION=例：撮影日から1年間（運用に合わせる）
CONSENT_STORAGE_DIR=/absolute/path/to/private-consents
CONSENT_OPERATOR_TOKEN=32文字以上のランダムな運営者専用の秘密値
RESEND_API_KEY=送信権限のあるResendキー
CONSENT_MAIL_FROM=控え送信元 <receipts@verified-domain.example>
```

- `CONSENT_CONTACT` は相談先と返信先メールです。Resendで送信元ドメインの認証が必要です。送信サービスの料金・制限は別途確認してください。
- 保存先は公開ディレクトリ、Git、共有フォルダの外にしてください。サーバーに書込可能な永続領域を使ってください。Vercel等の一時ファイルシステムへはこの構成をそのまま配備できません。
- 主催者・連絡先・保存期間・絶対パスの保存先・運営者トークンがない場合、同意保存を無効にします（フォームは表示します）。メールだけ未設定の場合は同意保存とPDF取得は可能ですが「未送信」と表示します。
- 運営者がトークンを手入力します。ブラウザへ配布する環境変数にはせず、参加者へ渡さないでください。公開運用にはTLS、運営者認証、アクセス制御・レート制限、端末ロック、暗号化、バックアップ、削除手順、保存期間の定期管理が必要です。この実装は信頼された運営端末向けです。

## 操作と保存

1. `/live` の準備画面では会話・記録と掲載予定の確認チェックのみを入力します。掲載範囲と署名は、会話・ログ除外・分析候補確認・最終分析の後に配置します。冒頭チェックは公開許可ではありません。
2. 変化した約款を確認し氏名・メール、年齢確認、同意チェックを入力します。18歳未満は保護者氏名を入力し保護者本人が署名します（自動本人確認は行いません）。
3. 最終分析の末尾でA/B/Cを選び、本人・保護者情報と同意項目を確認して署名します。運営者トークンで同意を保存し、既存のインタビュー撮影IDへ紐付けます。署名保存なしの素材は公開不可です。デモは実署名を収集しません。
4. サーバーが受領した同意JSON、署名PNG、PDF、約款全文・バージョン、選択、署名日時、撮影ID、サーバー受領日時、SHA-256を専用ディレクトリへ保存します。同じ同意IDの上書きは拒否します。ハッシュは改変検出の補助であり、公的タイムスタンプ・第三者認証ではありません。署名日時は端末時刻です。
5. ResendにPDFを添付して送信。正常応答時のみ「送信受付」と表示します。受信・既読は保証せず、失敗・未設定時はPDFダウンロードと再送ボタンを表示します。同じ控えの再送には同じidempotency keyを使います。サービス側の保持期間を超えた不確実な再送は管理画面で送信状態を確認してください。
6. インタビューIDと撮影IDを共通化。音声のダウンロード名にもIDを付けます。外部カメラの動画は同じIDで手動管理してください。外部動画の自動認識・ファイル内容の暗号学的紐付けはありません。
7. 終了後は履歴に同意とPDFが保存されます。個人情報入りの控えはSNS素材JSONに含めず、履歴の「掲載同意・控え」から取得します。署名前の失敗でもサーバー保存済みの場合があります。同意IDで運営者が確認してください。

同意はブラウザの準備設定には永続化しません。署名直後にリロードした場合、完了済みの同意はサーバー側の撮影IDで管理してください。ブラウザ履歴の削除はサーバー同意記録を削除しません。保存期間が過ぎた記録や削除請求は主催者がサーバー・端末・メールの各コピーに対して処理してください。

## 加工の責任と確認

顔モザイク、顔カット、音声加工は自動実装していません。B/Cでも原録音・原録画には本人が含まれるため、主催者が公開前に加工・確認する必要があります。同意記録があることと、完成動画が同意範囲を守っていることは別です。氏名や背景など顔以外の識別要素も確認してください。本人の氏名・連絡先・署名・控え自体を公開しないでください。

## 手動確認

- 日本語 / 英語、スマホで3つの選択、動的約款、署名リセット・確定、必須入力と保護者署名を確認。
- B/Cでは自動加工されない旨が表示され、冒頭チェックが未完了なら開始不可、最終署名なしなら公開許可がないこと。
- 設定不足、誤ったトークン、通信断、メール拒否で送信成功と表示されないこと。
- 正式な検証用メールへ送信し、日本語・英語PDFの全約款・署名・日時・撮影IDが読めること（本開発では実メール未送信）。
- 最終履歴からPDFを取得でき、録音ファイル名・履歴ID・PDFの撮影IDが一致すること。
