# 街頭インタビューと編集素材

## 収録の流れ

準備で聞き方・聞き手の年代・ジェンダー表現を選ぶ。年代は語彙とテンポに、男性の選択は cedar の音声に反映する。女性とニュートラルは marin を使う。年齢や性別からゲストの経験を決めつけない。

同期音の開始を収録時計に記録し、AI は接続後に自分から最初の質問をする。9分で締めの指示を更新し、10分で確認へ進む。会話プロンプトは `prompts/interviewer.md` と聞き方別のファイルを組み合わせる。

マイク・AIのWebRTC音声・同期音を同じMediaRecorderの音声に混ぜる。カメラを有効にした場合は映像トラックも含む。収録データは端末内のBlobで、再読み込みすると失われるため、終了後に保存する。

## 字幕と外部カメラ

保存した音声を使う場合、字幕基準は「保存音声の先頭」。外部カメラの同期音の開始を0秒に編集する場合は「同期音の開始」。追加のオフセットは正の値で字幕を遅らせる。SRTと編集CSVはこの設定を共有し、JSONは常に収録開始からのミリ秒で記録する。

発言ごとの開始・終了は確認画面で修正できる。時刻は発話区間からの推定で、単語レベルの強制アラインメントではない。AIの音声出力開始・停止イベントとゲストの発話イベントを使い、後の履歴更新で過去の終了時刻を延長しない。実カメラの映像・音声で同期を確認してから公開する。

除外した発言は誌面、字幕、CSV、JSONの会話から除く。音声・映像ファイル自体は未編集の原本なので、除外箇所の音声と映像のカットは動画編集ソフトで行う。

## 可視化の選定と根拠

- 語の大きさはゲスト発言内の実出現回数。AIの繰り返しは含めない。日本語はIntl.Segmenterで分割し、漢字・カタカナ中心の語を採用するため、ひらがなの語や活用の集約には限界がある。
- 過去・現在・未来は時間表現に一致した発言数。重複を認め、発言を開いて確かめられる。
- 感情は辞書に現れた表現。否定や皮肉を解析せず、心理状態のスコアにはしない。
- 自己決定理論の自律性・有能感・関係性を参考に、「自分で選ぶ」「できるようになる」「人とつながる」の表現を探す。独自の辞書による探索用のレンズであり、妥当性検証済みの心理尺度ではない。数から欲求の強さや満足度を推定しない。
- 開かれた問い、反映、本人の訂正を促す聞き方をプロンプトに使用。臨床研究の知見を街頭インタビューに応用する設計判断であり、同じ効果を保証するものではない。

## 自己分析マインドマップ

### 1問ずつのゴールバック・インタビュー

コスメは商品レビューの主題ではなく、本人の人生を聞くための入口。商品・使用感の質問は1〜2問を目安にし、本人が語った「切り替え」「自分で選ぶ」「誰かと過ごす」等を受けて日常の場面へ広げる。そこから具体的な出来事、選択や転機、今と昔の変化を聞く。話が仕事・学び・趣味・関係性へ移ったら主題として追い、商品へ戻す必要はない。関連する記憶や感情がない回答では、さらに使い方を聞くことを既定にせず、一日の過ごし方など答えやすい話へつなぐ。家族・仕事・成功体験を着地点に決めつけず、本人が続けたい場合はコスメの話も尊重する。デモ後半も家族との時間→学校の記憶→人の話を待つ姿勢→仕事での経験→これから大切にしたい時間と展開する。

共通プロンプトは、短い受け止め＋1問を通常応答の基本にする。疑問符が1つでも「いつ・誰と・なぜ」をまとめて要求しない。内部で5要素を未確認／本人が語った／話したくないに分け、直前の回答とつながる未確認要素を1つだけ聞く。話したくない要素を再追及したり、家族・子ども・安心感へ誘導したりしない。

進行はアイスブレイク→場面の具体化→理由・原体験への問い→本人の一言とまとめ、の4フェーズ。場面・比較・五感・原体験・仮定・第三者視点・要約の7アプローチを使い分ける。第三者視点は本人の想像として扱い、第三者の事実にはしない。共感で未確認の感情を足さず、AIの愛用品・身体経験・家族の記憶も捏造しない。締めや拒否、安全上の停止では質問を足さない。これらはモデルへの指示であり、出力を機械的に保証するものではない。ローカルテストは共通指示とスタイルの整合性を検証し、実音声の質問品質は別途確認が必要。

### 表示言語と冒頭の多言語対応

準備の言語選択がUI全体（同意・ナビゲーション・確認・保存・分析・履歴・利用料）の表示言語を決める。選択時に保存し、再読み込み後は初回描画後に復元する。サーバーと最初のブラウザ描画は日本語の同一初期値で、ブラウザの言語を描画中に参照しない。英語デモには全発言の英語台本を使う。本人の名前・場所・発言・引用は自動翻訳しない。

英語モードの音声インタビューは英語で開始し、最初のまとまった回答が韓国語・中国語等ならその言語で続けるようモデルに指示する。挨拶・名前・アクセントだけで切り替えず、不明なら短く確認する。一度決めた会話言語は明示的な変更依頼がない限り維持する。UIは英語のまま。日本語モードは冒頭発話による自動切替を無効化する。英語モードの文字起こしからja/enの限定を外し、原語での文字起こしを指示する。これはモデルの言語判断に依存し、ローカルテストは設定・辞書・台本のみを検証する。実音声での切替品質は別途確認が必要。

### ビジュアルと操作

インタビュー画面はミスト背景（#F7F9F9）、ローズ（#92536B）、淡いローズ（#F3E8ED）を基本とする。既存のZen Maru Gothicを会話UIの単一書体として維持し、本文16px、質問20px、見出し25〜31pxで整理する。誌面の書体・配色は変更しない。主要ボタンは高さ52px、補助ボタンは最小48×48 CSS px。影は下向きの1種類のみ。操作の反応は160ms、動きを減らす設定では無効化する。

モバイルでは会話を先に表示し、マップは「今の気づきを見る」で開く。終了操作は下部に追従する。会話の5項目表示は道案内であり、実際の進捗やAI内部状態を推定しない。マップは5カテゴリ別の曲線とキーワード下線を使い、本人が最重要と明示した価値観だけを雲形で囲む。モバイルには48px以上の操作領域を持つカテゴリ別一覧を併設する。SVG全体表示の文字は縮小されるため、小画面では一覧または拡大表示を使う。

会話中の「自己分析マップ」、確認画面、保存画面で同じ5分類の図を表示する。主枝は「きっかけ・悩み」「原体験・記憶」「現在の習慣・感情」「未来・継承」「コアな価値観」。各枝4語を上限に、ゲストの原文に存在する語句を抽出する。同一表記はカテゴリをまたいでも1ノードに統合し、分類の出現回数で配置を決め、同数なら価値観・未来・記憶・きっかけ・現在の順を使う。異なる表記を同義語としてまとめることはしない。カテゴリは簡易ルールによる候補で、文脈全体を理解するものではない。

追加のAI APIは呼ばない。AI・ホスト・除外した発言は対象外。「母→家族」「話を聞く→傾聴」の言い換えは禁止。★は大切さの明示表現、雲形は最重要の明示表現が一意に特定できた場合のみ。本人の確認を前提とし、強みや深層心理を断定しない。

共起だけでは矢印を作らない。「ので」「だから」「おかげで」「ことで」および「〜のは〜からです／ためです」に合う本人の文から、両端が一意に決まる理由だけを候補として表示する。否定語や複数の候補がある場合は接続しない。客観的な因果の証明ではなく、本人が述べた理由である。3行要約は根拠の引用を使い、不足分は未確認と表示する。会話をまたぐ因果、皮肉、複雑な文法は解析しない。SVGと根拠付きツリーを保存できる。

プロンプトは印象的な体験1〜2個を軸に、行動・気持ち・理由・価値・未来を3〜6段階で聞く方針を加えた。質問数や「なぜ」の繰り返しを優先せず、話す意思と既に語られた内容を尊重する。

## 誌面の構成

### 総合アナリティクス・マガジン

利用者向けの標準フローは「含めたくない発言の選択→分析候補への本人の確認→最終マップ・統計と説明」の3段階。動画素材・SNS書き出しはこのフローに入れない。分析結果画面は、①大切だと話したこと、②行動や気持ちの理由、③これからの希望、の平易な説明を最初に表示する。根拠を開いて本人が「合っている／少し違う／まだ分からない」を選べる。確認内容はフローの状態に保持し、最終結果の履歴にも保存する。「少し違う」「まだ分からない」「未回答」は未確定と表示し、合意済みと扱わない。文字起こしが変わった場合は別の根拠キーとして扱い、古い確認を引き継がない。

最終段階でマップ・統計と説明を提示する。投稿用の誌面構成・画像比率・音声・字幕・SNS素材の保存操作は、履歴詳細の「素材保存・SNS書き出し」だけで提供する。心理診断や客観的な強みの断定はしない。証拠がない項目は未確認とし、弱点とみなさない。分析画面への遷移でsuggest-copy APIは呼ばず、ローカルで下書きを作る。下書きに必要なQ&Aが不足していても分析は表示し、結果メモを保存できる。履歴詳細は /live/archive/[id]。有効な下書きがない短い会話でも、分析結果・原文ログ・存在する録音は参照できる。

会話終了後の確認画面と保存画面に、ヘッダー・本人の引用→アナリティクス→5軸マインドマップ→理由の3行説明→プロンプト構成とメタデータ、の順で単一レポートを表示する。確認画面の編集・除外をローカルで再集計する。保存画面では編集済み誌面のタイトルとリードを使う。引用は分析対象ゲストの発言に一致するものだけを使う。

レーダーは「伝統・継承」「安心・安定」「他者との関わり」「自己表現」「変革・挑戦」の表現がある発言の割合（0〜100）。該当する発言数÷分析対象の空でないゲスト発言数、を四捨五入する。AI・ホスト・除外発言は分母・分子から除く。0は言及なし、空データはnull。否定や引用も数える場合があるため、心理的な安定度・共感力・能力の評価としては扱わない。心理スコアとアイデンティティ安定度は根拠となる尺度がないため未算出。感情ドライバは、明示された理由と感情語が一意に接続できる候補のみ。時間軸の列に母・娘等を固定挿入せず、継承や因果を推測しない。

思考密度は表示ノードのカテゴリ別構成比で、最大剰余法により合計100%に調整する。各カテゴリ4語の表示上限があるため、実際の関心や思考量の推定には使わない。動機ベクトルはポジティブ追求／リスク回避・安心の辞書表現を含む発言数の構成比。同じ発言が両方向に該当すれば各1件、未分類は分母から除き、両方向・未分類の件数を別記する。否定語のある文は除外するが、複雑な否定や皮肉の解析は保証しない。該当0件では割合を作らない。

タイプ名は最多ノードのカテゴリを記述する「今回の会話の仮タイプ」。同数なら単一カテゴリを選ばない。強み・人物診断・処方箋と称さず、観察事実・解析上の注意・任意の振り返り質問を表示する。各式と辞書をJSONメタデータに含める。

JSON保存時に分析日時（ISO UTC）、ローカル解析の版、算出式、正規表現、原文・根拠IDと5セクションの表示用データを記録する。追加LLM呼び出しは0。トークン数やtemperatureは適用外で、音声会話の利用量とは別。プロンプト欄は設計要素と参照先であり、実際にAPIへ送信された全文の記録ではない。JSONは会話本文を含むため、共有前に内容を確認する。

引用中心・対話中心・見開きの3構成と、乳白と墨・夜の鏡・青磁の瓶の3配色を組み合わせる。選択を下書きに保存し、保存画面の「選んだ誌面を保存」で同じ見た目をPNGにする。公開用の引用はゲストの発言を根拠にする。

既定の乳白と墨は紙色#F9F9F7、本文#2B2B2B、アクセント#8C6B73。プレビュー外枠とQ&Aの背景カードは廃止し、単一の紙面と余白で整理する。タイトルと引用には既存の明朝体、質問には小さめで太いゴシック体を使う。引用の原文は編集せず、大きな引用符で挟む。質問と回答はインデント・1pxの区切り線で区別する。角丸・影は付けない。見本のタイトルや引用を実データへ固定挿入しない。

## 実機で残す確認

10分の実会話、ヘッドホン使用時のAI音声混合、実カメラの同期音合わせ、日英の会話品質、すべての誌面構成と比率で長い発言が収まること。自動テストのみでこれらを完了と判定しない。

## 履歴と収録ファイルの保存

最終画面の表示時に、このブラウザのIndexedDBへ同一セッションIDで自動保存する。確認内容・録音Blob・収録開始時刻を保存対象に追加した。クラウドへアップロードしたりSNSへ投稿したりはしない。容量不足・保存拒否等は画面に失敗と再試行を表示し、保存成功とは扱わない。履歴はこのブラウザ・端末に依存し、サイトデータ削除や端末変更では失われる。旧形式の履歴に録音がなくても開けるようにし、音声なしと明示する。

除外した発言は分析や誌面から外すが、元の録音ファイルから自動削除はしない。履歴は非公開の原素材を保持するため、素材保存画面に編集と公開許可の確認を明記する。外部動画のアップロード・音声同期・横縦動画合成は別段階で、まだ未実装。
