# 外部撮影とアプリ素材の合成方針

## 選択済みの縦動画テンプレート

本人を大きく表示し、字幕と関連するマップの枝を場面ごとに切り替える。人物・チャット履歴・全マップを3段に常時縮小する方式にはしない。

- 縦版：1080×1920、9:16。通常は人物を主役に、短い質問と回答字幕を表示する。
- 言葉を振り返る場面：本人の音声を保ったまま、該当するマップの1〜3語を拡大する。
- 締め：本人が語ったコア軸を表示する。未確認の価値観や因果を付け足さない。
- 横版：1920×1080、16:9。人物映像とチャット・マップを左右で構成する。
- 投稿先の上下・右側UIに重要な字幕を重ねない。余白は実際の投稿プレビューで確認する。

## インタビュー操作画面

会話中はチャットとライブマップのみを主役にする。スマホ幅（767px以下）はチャットかマップの単独表示で、初期表示はチャット。PCでは両方表示も選べる。画面幅の変更にも追従する。マップ単独時にも現在の質問を残す。分析ダッシュボードやファイル保存操作は終了後へ移す。

更新されたノード・根拠・枝に700msの演出を付け、無関係な操作では再生しない。動きを減らす設定では演出しない。話し始め／文字起こし待ち／マップ描画／反映済み／新語なし／失敗を区別する。文字起こし待ちは経過秒数を表示し、15秒以上では遅延と接続確認を案内する。完了予定秒数・進捗率は推定しない。

## 現在の収録・履歴出力

参加者の準備・会話・最終結果には動画編集ボタンや音声分離設定を増やさず、自動収録します。操作は履歴詳細の「素材保存・SNS書き出し」内「自分用・動画編集素材」に限定しています。これはUI配置による分離であり、運営者のログイン権限を新設したものではありません。

- 新しい本番収録では、既存のミックス録音に加えて本人マイク・AI受信音声を同じAudioContextから別々のMediaRecorderで保存します。AIが接続されなかった場合や未対応時は欠損・問題を記録し、存在しない音声を作りません。デモは実音声ではありません。
- チャット更新、遅延反映後のマップ更新、表示切替、AudioContext状態を、既存の収録開始基準の時計で記録します。イベントはReactの更新を観測した時刻で、実画面の全ピクセル・フレームを収録したものではありません。発話区間と反映時刻は別データです。
- 会話終了時に、署名・最終結果を待たず原素材をブラウザ履歴へ保存します。最終結果で編集・同意内容を更新保存します。署名なしの素材は公開不可です。保存失敗は最終結果の既存再試行で再保存できますが、容量不足等で成功しないまま閉じると保持できません。
- 履歴では原形式の音声、対応ブラウザでのWAV変換、SRT、CSV、編集後ログ、最終マップJSON/TXT/SVG、元の表示イベントと更新ごとのマップJSONをダウンロードできます。ZIP一括保存は無圧縮・ZIP32で、約4GB以上は個別保存してください。WAVはZIPに重複格納せず、必要な音声だけ後から変換します。変換は音質改善やサンプル単位の同期保証ではありません。
- ZIP内の `replay.html` は、同じフォルダ内のミックス音声に合わせてチャット・マップを再構成するオフライン確認用です。ZIPを展開して対応するPCブラウザで開いてください。マップ演出・レイアウトは簡易的な再現であり、実画面と完全同一ではありません。未対応の音声形式は原ファイルを編集ソフトで開いてください。
- 個人情報のある署名・同意PDF・連絡先は編集ZIPへ含めません。原音声・`raw/`・リプレイには除外した発言も残ります。全トラックと見える文字・枝を公開前に編集してください。共有用の安全な完成動画ではありません。
- 旧履歴には分離音声や過去イベントがなく、最終ログから実際の反映タイミングは復元できません。現在の保存はIndexedDBで、ブラウザ・端末のデータを消すと失われます。クラウド同期・長期保管保証はないため、運営者がZIP等をバックアップしてください。
- 分離音声はレコーダーごとのエンコーダー遅延があり、開始オフセット・推定終了時刻・実際のAudioContextサンプルレートを記録します。外部カメラは別途冒頭・終盤の拍手等で同期し、ドリフトを確認してください。iPad・外付けマイクでの実機検証は必要です。

## 次段階の実装（未実装）

外部動画の読み込み、音声波形による同期候補と手動補正、テンプレートの合成プレビュー、横・縦動画のエンコードは未実装です。チャット・マップのアニメーションMP4はこの素材ZIPでは生成しません。録音途中の分割永続保存・画面ロックやアプリ中断からの完全復旧も未対応です。外部カメラには同期用音声を残し、冒頭の手拍子等が両端末に録音されるようにします。
