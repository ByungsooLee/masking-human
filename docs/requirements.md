# 機能要件（THE HUMAN MIRROR）

> 履歴資料：旧段階の仕様・テスト計画を含みます。現在の `/live` の仕様と対話ノウハウは [インタビュー開発ナレッジ](interview-knowledge/README.md) を参照してください。以下の時間・質問数・未実装一覧・件数を現在の全体仕様として扱わないでください。

## 目的

コスメを入口に、参加者と AI が約 5〜8 分対話し、写真・動画作品の素材とする。AI は定型質問の繰り返しではなく、回答を理解したうえで非誘導的に問いを続ける。

## Phase 1（実装済み）

| ID | 要件 | 状態 |
|----|------|------|
| P1-1 | 5 段階ステージ（Observation → Closing）をアプリが管理 | 済 |
| P1-2 | 最大 8 問、1 ターン 1 問 | 済 |
| P1-3 | スキップ / 話題変更 / 早期終了 | 済 |
| P1-4 | テーマ A–E | 済 |
| P1-5 | Structured Outputs + Zod | 済 |
| P1-6 | mock / OpenAI 切替 | 済 |
| P1-7 | Web UI + CLI | 済 |
| P1-8 | Vitest 20 件以上 | 済 |
