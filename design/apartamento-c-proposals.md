# 案C「海外の暮らし雑誌型」— レイアウト2案

参考の考え方のみ（Apartamento 等）。誌名・ロゴ・紙面の転写はしない。

---

## バリエーション1「1ページ」

### 構図

写真をステージ上部に大きく。インタビュー本文は写真の下の余白（紙面の下段）に横書き。キャプションは写真左下の余白に小さく（名前／場所／日付を改行）。

### 色（名前付き）

| トークン | 値 | 用途 |
|---------|-----|------|
| `--color-ground` | `#e8ebe9` | 紙面の地（冷たいグレー、クリーム不使用） |
| `--color-ink` | `#252928` | 本文 |
| `--color-ink-muted` | `#5a635f` | AI の質問 |
| `--color-line` | `#b8c0bc` | 区切り（操作パネルのみ） |
| `--color-accent` | （写真から抽出） | ゲスト最新の言葉 |
| `--color-stage-letterbox` | `#141816` | ステージ外のレターボックス |

### 書体

- **Libre Franklin**（欧文・UI・AI 質問）— 生活誌の素直なサンセリフ。飾らないインタビュー調に合う。
- **BIZ UDPMincho**（和文・ゲスト引用）— 印刷物の本文感。太字に頼らず読める。

### 9:16 ASCII

```
+------------------+
|                  |
|     PHOTO        |
|              cap |
|                  |
+------------------+
| AI question      |
| Guest quote (acc)|
| older line       |
+------------------+
```

### 16:9 ASCII

```
+--------------------------------+
|           PHOTO                |
|                          cap   |
+--------------------------------+
| AI question    |  (余白)       |
| Guest quote    |               |
+--------------------------------+
```

### 見せ場

ゲストの**最新の一言**が `--color-accent`（写真由来）で現れる瞬間のみフェード（1回）。

### design.mdc 照合

| 禁止 | 当初の懸念 | 修正 |
|------|-----------|------|
| クリーム地 + テラコッタ | 雑誌風 cliché | クールグレー地、アクセントは写真由来のみ |
| INTERVIEWER ラベル | — | 使わない。サイズと sans で AI を下げる |
| 写真上グラデ帯 | 読みやすさの定番 | 使わない。文字は写真外の余白 |
| 中黒キャプション | — | 改行3行 |
| 角丸カード | — | ステージは直角、影なし |

## バリエーション2「見開き」

### 構図

- **16:9**: 左 55% 写真 + キャプション、右 45% インタビュー本文（縦方向は下寄せ）。
- **9:16**: 上 55% 写真、下 45% 本文（見開きを縦に折ったイメージ）。

### 色

バリエーション1と同じトークンセット（地・インク・アクセントの考え方を共有）。

### 書体

バリエーション1と同じ（Libre Franklin + BIZ UDPMincho）。

### 9:16 ASCII

```
+------------------+
|     PHOTO        |
|            cap   |
+------------------+
| AI question      |
| Guest quote      |
+------------------+
```

### 16:9 ASCII

```
+----------------+-------------+
|                | AI question |
|    PHOTO       | Guest quote |
|          cap   |             |
+----------------+-------------+
```

### 見せ場

右（または下）段にゲスト最新の言葉が入る瞬間。写真と言葉が**同時に見える**見開きのバランス。

### design.mdc 照合

| 禁止 | 当初の懸念 | 修正 |
|------|-----------|------|
| 新聞型段組 + 罫線だらけ | 見開き＝罫線になりがち | 罫線は使わず、余白と面積比だけで分割 |
| 01/02/03 番号 | — | 付けない |
| 全部下からフェード | — | ゲスト最新のみ |
